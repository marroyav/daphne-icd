
\section{Integration Scope and Strategy}\label{sec:int-scope}
\paragraph{Minimal Integration (PRR target).}
DAQ data taking with DAPHNE MEZZ/V2 within SNR and bandwidth limits; working timing endpoint integration; configuration path through DAQ; decode of frames including peak descriptors. Excludes PDS trigger chain integration and full online calibration.
\paragraph{Full Integration (post‑PRR).}
Run‑control orchestrated calibrations; validated TP/TA formats and latency budget; unified trigger coordination.
