
This Interface Control Document (ICD) defines the boundary and responsibilities between the Photodetector System (PDS) front-end electronics based on DAPHNE and the Data Acquisition (DAQ) system for both Horizontal Drift (HD) and Vertical Drift (VD) detectors. It captures the physical, electrical, logical, and software interfaces, the data formats, performance and timing budgets, and the verification/validation plan. Revision 8 fixes the configuration boundary with Slow Control (SC): DAQ owns configuration that determines acquired data, SC owns equipment lifecycle, power, availability and protection, and both use a shared role-aware PDS OPC-UA gateway. Detector Protection System (DPS) inhibits and protective actions remain authoritative.
