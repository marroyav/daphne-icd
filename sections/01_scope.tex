
\section{Scope and Purpose}
This Interface Control Document (ICD) defines the boundary and responsibilities between the Photodetector System (PDS) front-end electronics based on DAPHNE and the Data Acquisition (DAQ) system for both Horizontal Drift (HD) and Vertical Drift (VD) detectors. It captures the physical, electrical, logical, and software interfaces, the data formats, performance and timing budgets, and the verification/validation plan.
