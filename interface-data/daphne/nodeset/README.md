# Project-specific OPC-UA NodeSet

No approved project-specific DAPHNE NodeSet XML was available when this proposed
revision 8 review baseline was prepared. A placeholder XML file is intentionally
not supplied because it could be mistaken for an executable or approved
contract.

When the NodeSet is approved, add the exact controlled XML artifact here and
update `../manifest.yaml` with its version, status, source revision, and SHA-256
checksum. The NodeSet must remain consistent with the variable registry,
control-policy export, DAQ-to-OPC-UA mapping, permissions, and conformance tests.
